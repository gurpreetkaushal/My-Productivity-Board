# My Productivity Board

My Productivity Board is a simple task management web application where users can add and manage their tasks easily.

## Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Shows a popup message if the user tries to add an empty task

## How It Works

1. User enters a task in the input field.
2. User clicks the **Add** button.
3. If no task is entered, a **"Please enter a task"** message is displayed.
4. If a task is entered, it is added to the task list.
5. Each task has three buttons:

   * **Edit** – Edit the task
   * **Delete** – Delete the task
   * **Done** – Mark the task as completed
